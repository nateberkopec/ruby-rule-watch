# Ruby Rule Watch

A moderator-only Devvit app for /r/ruby that reports possible rule violations to the mod queue for human review. It does not remove, approve or lock content, ban users, or make public replies.

- [Privacy policy](privacy/)
- [Terms](terms/)
- [Source code](https://github.com/nateberkopec/ruby-rule-watch)

Questions about the installation can be sent to the [/r/ruby moderators](https://www.reddit.com/message/compose?to=%2Fr%2Fruby).
